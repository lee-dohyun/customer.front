# 내 회원 등급과 혜택 확인하기 사용 설명서

| 항목 | 내용 |
|---|---|
| 대상 | 고객(회원) |
| 화면 주소 | <https://customer.posselect.com/mypage> |
| 필요한 권한 | 로그인만 |
| 최종 확인 | (미확인) — 2026-10-02 자동 테스트(문구·계산)만 통과. 배포 전이라 실제 화면으로는 아직 확인하지 못했다 |
| 관련 이슈 | lee-dohyun/gateway#81 |

## 1. 이 기능으로 할 수 있는 일
마이페이지에서 지금 내 회원 등급, 그 등급으로 받는 할인 혜택, 다음 등급까지 얼마를 더 구매하면 되는지를 볼 수 있다.

## 2. 시작하기 전에
- PosSelect 회원으로 로그인해 있어야 한다. 로그인하지 않았으면 로그인 화면으로 이동한다.

## 3. 따라 하기
### 3-1. 내 등급 확인하기
1. <https://customer.posselect.com/mypage> 로 들어간다 → 이메일이 적힌 칸 아래에 「회원 등급:」으로 시작하는 칸이 보인다.
2. 「회원 등급:」 옆의 이름(일반·실버·골드·VIP)이 지금 내 등급이다.
3. 「혜택:」 줄에서 등급 할인율을 확인한다 → 예: 「2% 할인」.
4. 맨 아래 줄에서 다음 등급까지 남은 금액을 확인한다 → 예: 「골드 등급까지 550,000원 남았습니다. (최근 6개월 구매확정 금액 기준)」.

## 4. 입력 항목 설명
해당 없음 (보기만 하는 화면이다).

## 5. 상태와 진행 흐름
| 상태(화면 표시) | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 「일반」 | 가입하면 받는 기본 등급. 「등급 할인 혜택이 없습니다.」 | 최근 6개월 구매확정 금액 30만원 이상이면 실버 |
| 「실버」 | 「2% 할인」 | 100만원 이상이면 골드 |
| 「골드」 | 「5% 할인」 | 300만원 이상이면 VIP |
| 「VIP」 | 「10% 할인」. 「현재 최고 등급입니다.」 | 없음 |

등급 이름·할인율·기준 금액은 운영 정책에 따라 바뀔 수 있고, 화면에는 항상 현재 정책 값이 표시된다(위 표는 2026-10-02 기준).

## 6. 자주 보는 메시지와 해결 방법
| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 「골드 등급 기준을 채웠습니다. 다음 등급 산정(월 1회) 때 반영됩니다.」 (등급 이름은 내 다음 등급) | 기준 금액은 넘겼지만 등급은 한 달에 한 번만 다시 계산된다 | 다음 산정까지 기다린다. 따로 할 일은 없다 |
| 「다음 등급은 골드입니다. 남은 금액을 불러오지 못했습니다.」 (등급 이름은 내 다음 등급) | 구매 금액을 일시적으로 가져오지 못했다 | 잠시 뒤 새로 고친다. 계속되면 문의한다 |
| 「회원 등급:」 칸이 아예 안 보인다 | 등급 정보를 일시적으로 가져오지 못했다 | 잠시 뒤 새로 고친다. 계속되면 문의한다 |

## 7. 알아 둘 제한 사항
- 구매 금액은 **배송이 완료된 주문만** 센다. 결제만 했거나 배송 중인 주문, 취소·환불된 주문은 빠진다 — 주문 뒤 환불을 반복해 등급을 올리는 것을 막기 위해서다.
- **최근 6개월** 금액만 센다. 그래서 구매가 줄면 등급이 내려갈 수 있고, 남은 금액도 날짜가 지나면 달라질 수 있다.
- 등급은 **한 달에 한 번** 다시 계산된다. 기준을 넘겨도 바로 오르지 않는다 — 주문·환불마다 등급이 바뀌면 혜택이 오락가락하기 때문이다.
- 비회원으로 한 주문은 금액에 포함되지 않는다 — 어느 회원의 주문인지 확인할 수 없기 때문이다.
