## 1. 이 기능으로 할 수 있는 일
마이페이지에서 내 주문을 기간별로 찾아보고, 주문 하나를 눌러 상품·결제 금액·배송지·운송장 번호를 확인한다. 운송장이 등록된 주문은 「배송 조회」 버튼으로 배송 위치를 볼 수 있다. 출고 전에는 상품별로 주문을 취소하고, 배송 완료 후 7일 안에는 상품별로 반품을 신청할 수 있다.

## 2. 시작하기 전에
로그인해야 한다. 비회원 주문은 이 화면에서 보이지 않는다.

## 3. 따라 하기
### 3-1. 기간으로 주문 찾기
1. 마이페이지의 「주문내역」 아래에서 「전체」「1개월」「3개월」「6개월」「1년」 중 하나를 누른다 → 오늘을 끝으로 그 기간에 한 주문만 최신순으로 보인다.
2. 주문이 10건보다 많으면 목록 아래에 「주문 더보기」가 보인다. 누르면 다음 10건이 이어서 붙는다.

### 3-2. 주문 상세 보기
1. 목록에서 「주문 #N · 날짜 · 상품 N종」을 누른다 → 주문 상세 화면이 열린다.
2. 상세 화면에서 확인할 수 있는 것:
   - 「주문 상품」: 상품 이름 × 수량, 줄마다 금액
   - 「결제 금액」: 「상품 합계」, (할인이 있으면) 「회원 등급 할인」, 「배송비」(없으면 「무료」), 「결제 금액」, 결제일시
   - 「배송지」: 받는 사람·연락처·주소
   - 「배송 정보」: 배송 상태·택배사·운송장 번호·출고 일시(배송이 끝났으면 배송 완료 일시)
3. 「← 마이페이지」를 누르면 목록으로 돌아간다.

### 3-3. 배송 조회하기
1. 주문 상세의 「배송 정보」에서 「배송 조회」를 누른다 → 새 창에서 택배사 이름과 운송장 번호로 검색한 결과가 열린다.

### 3-4. 주문 취소하기 (출고 전)
1. 주문 상세 맨 아래 「취소·반품」에서 「주문 취소」를 누른다.
2. 취소할 상품마다 수량을 고른다(0개는 취소하지 않음). 결제 전 주문은 고를 수 없고 「결제 전 주문은 전체만 취소할 수 있습니다.」가 보인다.
3. 「취소하기」 → 「선택한 상품을 취소할까요? 결제한 경우 바로 환불됩니다.」에서 확인을 누른다.
4. 바로 처리된다. 「취소·반품」 목록에 「취소 완료」와 「환불 N원」이 보인다. 모든 상품을 취소하면 주문 상태가 「주문 취소」가 된다.

### 3-5. 반품 신청하기 (배송 완료 후 7일 안)
1. 「취소·반품」에서 「반품 신청」을 누른다.
2. 반품할 상품의 수량과 「반품 사유」(「단순 변심」「상품 불량·파손」「다른 상품이 왔어요」)를 고르고, 필요하면 상세 사유를 적는다.
3. 「반품 신청하기」를 누른다 → 목록에 「반품 접수됨(검토 중)」이 보인다.
4. 쇼핑몰이 확인하면 「완료」와 「환불 N원」이, 받아들이지 않으면 「반려」와 「반려 사유: …」가 보인다. 반려된 상품은 다시 신청할 수 있다.

## 4. 입력 항목 설명
| 항목 | 필수 | 형식·제한 | 예 |
|---|---|---|---|
| 취소·반품 수량 | 한 상품 이상 | 0 ~ 아직 신청하지 않은 수량 | 1개 |
| 반품 사유 | 반품만 필수 | 단순 변심 / 상품 불량·파손 / 다른 상품이 왔어요 | 단순 변심 |
| 상세 사유 | 선택 | 500자 이내 | 사이즈가 맞지 않아요 |

## 5. 상태와 진행 흐름
| 상태(화면 표시) | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 「결제 대기」 | 주문은 만들어졌지만 결제가 끝나지 않았다 | 결제를 마친다 |
| 「결제 완료」 | 결제가 끝났다. 「아직 출고 전입니다. 운송장이 등록되면 여기에 표시됩니다.」 | 판매자가 운송장을 등록하기를 기다린다 |
| 「배송 중」 | 운송장이 등록돼 택배사로 넘어갔다 | 「배송 조회」로 위치를 본다 |
| 「배송 완료」 | 배송이 끝났다 | 없음 |
| 「주문 취소」「환불 완료」 | 모든 상품이 취소되거나 반품·환불됐다 | 없음 |
| 취소·반품 「접수됨(검토 중)」 | 반품 신청이 접수돼 쇼핑몰이 확인 중이다 | 기다린다 |
| 취소·반품 「완료」 | 환불이 끝났다(취소는 신청 즉시) | 없음 |
| 취소·반품 「반려」 | 쇼핑몰이 반품을 받아들이지 않았다. 사유가 함께 보인다 | 필요하면 문의한다. 그 상품은 다시 신청할 수 있다 |

## 6. 자주 보는 메시지와 해결 방법
| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 「주문을 찾을 수 없습니다.」 | 없는 주문번호이거나 다른 사람의 주문이다 | 마이페이지 목록에서 내 주문을 다시 누른다 |
| 「주문 정보를 불러오지 못했습니다. 잠시 후 다시 시도해주세요.」 | 주문 정보를 일시적으로 가져오지 못했다 | 잠시 뒤 새로 고친다. 계속되면 문의한다 |
| 「주문 내역이 없습니다.」 | 고른 기간에 주문이 없다 | 「전체」나 더 긴 기간을 누른다 |
| 「신청할 상품과 수량을 골라주세요.」 | 모든 상품의 수량이 0개다 | 한 상품 이상 수량을 고른다 |
| 「지금 주문 상태에서는 이 신청을 할 수 없습니다.」 | 그 사이 출고됐거나(취소 불가) 아직 배송 완료 전이다(반품 불가) | 화면을 새로 고쳐 주문 상태를 확인한다 |
| 「신청할 수 있는 수량을 넘었습니다. 이미 신청한 상품이 있는지 확인해주세요.」 | 같은 상품을 이미 신청했다 | 「취소·반품」 목록을 확인한다 |
| 「반품은 배송 완료 후 7일 안에만 신청할 수 있습니다.」 | 배송 완료 후 7일이 지났다 | 고객센터로 문의한다 |
| 「결제 전 주문은 일부 상품만 취소할 수 없습니다. 주문 전체를 취소해주세요.」 | 결제 전 주문에서 일부만 취소하려 했다 | 전체를 취소한다 |

## 7. 알아 둘 제한 사항
- 기간은 한국 날짜 기준이고 양 끝 날짜를 포함한다.
- 배송은 주문 1건당 1건만 있다(나눠서 보내는 부분 배송은 없다).
- 「배송 조회」는 택배사 홈페이지로 바로 가지 않고 검색 결과를 연다. 택배사 이름은 판매자가 입력한 그대로라, 택배사별 조회 주소를 미리 정해 둘 수 없었기 때문이다.
- 환불 금액은 상품 금액에서 회원 등급 할인 몫(상품 금액 비율)을 뺀 금액이다.
- 출고 전 취소와 「단순 변심」 반품은, 남은 상품이 무료배송 기준 금액 아래로 떨어지면 처음에 면제됐던 배송비를 환불 금액에서 뺀다. 마지막 상품까지 돌려받으면 낸 배송비도 돌려준다.
- 「단순 변심」 반품은 상품에 안내된 반품 배송비(편도)를 환불 금액에서 뺀다. 「상품 불량·파손」「다른 상품이 왔어요」는 빼지 않는다(쇼핑몰이 확인하면서 사유를 바꿀 수 있다).
- 운송장이 등록된 뒤(배송 중)에는 취소도 반품도 신청할 수 없다. 받은 뒤 반품을 신청한다.
- 교환 신청은 아직 없다. 반품 후 다시 주문한다.

## 8. 문의
주문·배송 문의는 쇼핑몰 고객센터로 연락한다.
