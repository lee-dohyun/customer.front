| 필요한 권한 | 로그인 |
| 최종 확인 | 2026-10-02 — 등급별 주문 할인(일반 0%·실버 2%·골드 5%)은 운영 주소에서 주문 요청 단위로 확인(order.api `bd3a89d`, auth.api `731d238`). **마이페이지 등급 카드의 브라우저 화면은 (미확인)** |

> 양식: [사용자 설명서 표준](https://github.com/lee-dohyun/architecture/blob/main/docs/USER_GUIDE_STANDARD.md)

## 1. 이 기능으로 할 수 있는 일

마이페이지에서 내 회원 등급, 등급 할인율, 다음 등급까지 남은 금액을 확인합니다.
등급 할인은 주문할 때 자동으로 적용됩니다.

## 2. 시작하기 전에

- 로그인해야 합니다.

## 3. 따라 하기

1. 마이페이지를 엽니다 → 이메일 카드 아래에 등급 카드가 보입니다.
2. 카드에서 다음을 확인합니다.
   - 「회원 등급: (등급 이름)」
   - 「주문 금액의 N%를 할인받습니다.」 또는 「등급 할인이 없는 등급입니다.」
   - 「최근 6개월 구매확정 금액: N원」
   - 「(다음 등급) 등급(N% 할인)까지 N원 남았습니다.」
3. 주문하면 등급 할인이 자동으로 빠집니다. 장바구니에서 「결제 예정 금액」으로 미리 볼 수 있습니다.

## 4. 입력 항목 설명

해당 없음(보기 전용 화면입니다).

## 5. 상태와 진행 흐름

| 등급 | 최근 6개월 구매확정 금액 | 주문 할인 |
|---|---|---|
| 일반 | 30만원 미만 | 없음 |
| 실버 | 30만원 이상 | 2% |
| 골드 | 100만원 이상 | 5% |
| VIP | 300만원 이상 | 10% |

등급은 매월 1일에 다시 산정됩니다. 구매확정 금액이 줄면 등급이 내려갈 수 있습니다.

## 6. 자주 보는 메시지와 해결 방법

| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| (다음 등급) 등급 기준을 채웠습니다. 다음 달 1일 산정 때 반영됩니다. | 기준 금액은 넘었지만 등급 산정이 월 1회라 아직 반영 전 | 다음 달 1일 이후 다시 확인 |
| 가장 높은 등급입니다. | VIP 등급 | - |
| 사용자 정보를 불러오지 못했습니다. | 로그인이 만료됨 | 다시 로그인 |

## 7. 알아 둘 제한 사항

- 구매확정 금액은 **배송 완료된 주문**만 셉니다. 결제만 한 주문, 취소·환불된 주문은 빠집니다.
- 구매확정 금액은 실제 결제 금액(등급 할인을 뺀 금액) 기준입니다.
- 등급 카드가 보이지 않으면 등급 정보를 불러오지 못한 것입니다. 잠시 후 새로 고침하세요. 금액 줄만 안 보이면 주문 집계를 불러오지 못한 것입니다.
- 할인액은 원 미만을 버립니다.
- 적립금(포인트)은 없습니다.

## 8. 문의

주문·등급 문의는 쇼핑몰 고객센터로 연락해 주세요.
