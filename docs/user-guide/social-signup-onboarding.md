# 간편 로그인으로 처음 들어와 가입 마무리하기 사용 설명서

| 항목 | 내용 |
|---|---|
| 대상 | 고객(구글 등 간편 로그인으로 처음 들어온 사람) |
| 화면 주소 | <https://customer.posselect.com/onboarding> |
| 필요한 권한 | 간편 로그인만 |
| 최종 확인 | (미확인) — 2026-10-02 자동 테스트와, 배포 전 빌드를 브라우저로 띄워 모의 서버로 본 것까지만 통과. 실제 간편 로그인과 실제 문자 수신으로는 아직 확인하지 못했다 |
| 관련 이슈 | lee-dohyun/auth.api#42 |

## 1. 이 기능으로 할 수 있는 일
간편 로그인(구글)으로 처음 들어오면 회원은 바로 만들어지지만, 이메일로 가입할 때 받는 약관 동의와 휴대폰 본인 인증은 아직 안 한 상태다.
「가입 마무리」 화면에서 이 두 가지를 마치면 가입이 완료되고 마이페이지로 넘어간다.

## 2. 시작하기 전에
- 로그인 화면(<https://customer.posselect.com/login>)의 「구글 로그인」(G 버튼)으로 로그인해 있어야 한다.
- 문자를 받을 수 있는 본인 휴대폰이 필요하다.
- 이메일로 이미 가입한 사람은 이 화면을 쓸 일이 없다. 들어가도 곧바로 마이페이지로 넘어간다.

## 3. 따라 하기
### 3-1. 가입 마무리하기
1. 간편 로그인을 마친다 → 「가입 마무리」 화면이 열린다. (이미 마친 사람은 마이페이지가 열린다.)
2. 「휴대폰 번호」에서 국가를 확인하고 번호를 입력한 뒤 「인증요청」을 누른다 → 「인증번호」 칸이 나타나고 문자가 온다.
3. 문자로 받은 6자리 숫자를 「인증번호」에 넣고 「확인」을 누른다 → 「휴대폰 인증이 완료되었습니다.」가 보이고 버튼이 「인증완료」로 바뀐다.
4. 약관을 읽으려면 각 줄 오른쪽의 「보기」를 누른다 → 약관 본문 창이 열린다. 「닫기」로 닫는다.
5. 「(필수) 이용약관 동의」와 「(필수) 개인정보 수집 및 이용 동의」에 체크한다. 한 번에 하려면 「전체 동의」를 누른다(선택 항목인 마케팅 수신 동의도 같이 체크된다).
6. 「가입 완료」를 누른다 → 마이페이지가 열리면 끝난 것이다.

### 3-2. 지금 하지 않고 나가기
1. 화면 맨 아래 「로그아웃」을 누른다 → 로그인 화면으로 돌아간다.
2. 다음에 간편 로그인을 하면 다시 「가입 마무리」 화면이 열린다.

## 4. 입력 항목 설명
| 항목 | 필수 | 설명 | 입력 규칙 |
|---|---|---|---|
| 국가 | 필수 | 휴대폰 번호의 국가 | 목록에서 고른다. 목록에 없는 국가는 번호를 `+국가번호`부터 직접 입력한다 |
| 휴대폰 번호 | 필수 | 본인 인증을 받을 번호 | 숫자와 `-`, 공백, 괄호만. 인증을 마친 뒤에는 바꿀 수 없다(바꾸려면 새로 고침 후 다시 인증) |
| 인증번호 | 필수 | 문자로 받은 숫자 | 6자리 |
| (필수) 이용약관 동의 | 필수 | | 체크해야 가입이 완료된다 |
| (필수) 개인정보 수집 및 이용 동의 | 필수 | | 체크해야 가입이 완료된다 |
| (선택) 마케팅 정보 수신 동의 | 선택 | 체크하지 않아도 가입된다 | |

## 5. 상태와 진행 흐름
| 상태(화면 표시) | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 「가입 정보를 확인하는 중입니다...」 | 가입 마무리가 필요한지 확인하고 있다 | 기다린다 |
| 「가입 마무리」 화면 | 약관 동의와 휴대폰 인증이 남았다 | 3-1 을 따라 한다 / 고객 |
| 마이페이지가 열림 | 가입 마무리가 끝났다(또는 처음부터 필요 없었다) | 없음 |

## 6. 자주 보는 메시지와 해결 방법
| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 「휴대폰 번호를 다시 확인해주세요.」 | 번호에 숫자·구분기호 외의 글자가 있거나 자릿수가 맞지 않는다 | 번호를 다시 입력한다 |
| 「올바른 휴대폰 번호 형식이 아닙니다. 해외 번호는 국가번호부터 입력하세요(예: +81 90-1234-5678).」 | 고른 국가와 번호가 맞지 않는다 | 국가를 다시 고르거나 `+국가번호`부터 입력한다 |
| 「재발송은 60초 후에 가능합니다.」 | 인증번호를 방금 요청했다 | 1분 뒤 「재발송」을 누른다 |
| 「하루에 요청할 수 있는 인증번호 횟수를 초과했습니다. 잠시 후 다시 시도해 주세요.」 | 같은 번호로 하루 요청 횟수를 넘겼다 | 다음 날 다시 한다 |
| 「현재 휴대폰 인증을 이용할 수 없습니다. 잠시 후 다시 시도해 주세요.」 | 문자 발송이 일시적으로 안 된다 | 잠시 뒤 다시 한다. 계속되면 문의한다 |
| 「인증번호가 일치하지 않습니다.」 | 인증번호를 잘못 넣었다 | 문자의 숫자를 다시 확인한다 |
| 「인증번호가 만료되었습니다. 다시 요청하세요.」 | 문자를 받은 지 5분이 지났다 | 「재발송」을 눌러 새 번호를 받는다 |
| 「인증 시도 횟수를 초과했습니다. 다시 요청하세요.」 | 인증번호를 5번 틀렸다 | 「재발송」을 눌러 새 번호를 받는다 |
| 「필수 약관에 동의해주세요.」 | 필수 약관 두 개 중 체크하지 않은 것이 있다 | 두 개 모두 체크한다 |
| 「휴대폰 인증이 만료되었습니다. 다시 인증해주세요.」 | 인증하고 30분 넘게 지나 「가입 완료」를 눌렀다 | 「인증요청」부터 다시 한다 |
| 「이미 다른 계정에서 사용 중인 휴대폰 번호입니다.」 | 그 번호로 가입한 계정이 이미 있다(예: 이메일로 먼저 가입함) | 먼저 만든 계정으로 로그인한다. 본인 번호인데 계정이 기억나지 않으면 문의한다 |
| 「가입 정보를 확인하지 못했습니다. 잠시 후 다시 시도해주세요.」 | 가입 상태를 일시적으로 가져오지 못했다 | 잠시 뒤 새로 고친다. 「마이페이지로 가기」로 나갈 수 있다 |
| 「가입 마무리 중 오류가 발생했습니다.」 | 일시적인 오류 | 잠시 뒤 「가입 완료」를 다시 누른다. 계속되면 문의한다 |

## 7. 알아 둘 제한 사항
- 가입 마무리를 하지 않으면 **마이페이지가 열리지 않고 이 화면으로 돌아온다** — 주문·배송 안내에 쓸 본인 확인된 연락처가 없기 때문이다.
- **휴대폰 번호 하나로는 계정 하나만** 만들 수 있다 — 같은 사람이 여러 계정으로 혜택을 중복해 받는 것을 막기 위해서다. 이메일로 가입한 번호로 간편 로그인 계정을 또 만들 수 없다.
- 인증번호는 **5분** 동안만 쓸 수 있고, 인증한 뒤 **30분** 안에 「가입 완료」를 눌러야 한다 — 남이 본 인증번호나 오래된 인증으로 가입되는 것을 막기 위해서다.
- 카카오·네이버 로그인은 아직 쓸 수 없다(버튼이 눌리지 않는다).
