## 1. 이 기능으로 할 수 있는 일

상품 상세 화면에서 찜해 둔 상품을 한곳에서 보고, 다시 상품 화면으로 가거나 목록에서 지웁니다.

## 2. 시작하기 전에

- 로그인이 필요합니다. 로그인하지 않았으면 로그인 화면으로 이동합니다.
- 찜은 상품 상세 화면의 「♡ 찜하기」로 추가합니다.

## 3. 따라 하기

### 3-1. 찜 목록 열기
1. 어느 화면에서든 위쪽 「찜」(하트) 아이콘을 누릅니다 → 마이페이지가 열리고 「내 찜 목록」 위치로 이동합니다. (미확인)
2. 찜한 상품이 없으면 「찜한 상품이 없습니다.」가 보입니다.

### 3-2. 찜한 상품 다시 보기
1. 목록에서 상품 이름을 누릅니다 → 그 상품의 상세 화면이 열립니다.

### 3-3. 찜 목록에서 지우기
1. 상품 오른쪽 「삭제」를 누릅니다 → 「찜 목록에서 삭제하시겠습니까?」 확인 창이 뜹니다.
2. 확인을 누릅니다 → 그 상품이 목록에서 사라집니다.

### 3-4. 더 많은 찜 보기
1. 찜이 10개를 넘으면 목록 아래 「더보기」를 누릅니다 → 다음 10개가 이어서 보입니다.

## 6. 자주 보는 메시지와 해결 방법

| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 찜한 상품이 없습니다. | 찜한 상품이 없음(또는 목록을 불러오지 못함) | 상품 상세 화면에서 「♡ 찜하기」 |
| 삭제에 실패했습니다. | 일시적인 오류 또는 로그인 만료 | 다시 로그인한 뒤 시도 |
| 사용자 정보를 불러오지 못했습니다. | 로그인 만료 | 다시 로그인 |

## 7. 알아 둘 제한 사항

- 찜 목록은 따로 된 화면이 아니라 마이페이지 안에 있습니다 — 주문내역 아래에 보입니다.
- 목록에는 상품 이름만 보입니다(사진·가격은 상품 화면에서 확인).
- 판매자가 삭제한 상품은 찜 목록에서도 함께 사라집니다.
